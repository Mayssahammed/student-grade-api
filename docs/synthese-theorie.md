# Synthèse : XP, Scrum et DevOps

| | XP | Scrum | DevOps |
|---|---|---|---|
| Nature | Pratiques d'ingénierie | Cadre de gestion du travail | Culture + automatisation |
| Se concentre sur | Qualité du code | Organisation et livraison de valeur | Intégration, livraison, exploitation |
| Répond à la question | **Comment** bien développer ? | **Quoi** et **quand** ? | Comment livrer vite et sûrement ? |
| Exemples | TDD, binôme, refactoring, CI | Sprint, backlog, revue, rétrospective | CI/CD, pipeline, monitoring |
| Dans notre projet | Itération B | Backlog + DoD + sprints | GitHub Actions |
| Limite | Discipline exigeante | Aucune pratique technique imposée | Dépend de la qualité des tests |

## Conclusion
Les trois approches sont **complémentaires** : Scrum décide quoi réaliser et quand, XP
garantit que le produit est réalisé avec qualité, DevOps automatise son intégration et sa
livraison.
