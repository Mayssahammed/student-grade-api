# Fiche 1 : Extreme Programming (XP)

## 1. Définition
L'Extreme Programming est une méthode agile de développement logiciel centrée sur
l'**excellence technique** : tests fréquents, collaboration étroite, code simple et
adaptation continue aux changements (Beck, 2004).

## 2. Valeurs
Communication, simplicité, feedback, courage, respect.

## 3. Idées clés
- Le feedback rapide réduit le coût des erreurs.
- Les tests automatisés permettent de changer le code en confiance.
- Le code appartient à toute l'équipe ; il est amélioré en continu.
- Livrer de petites versions fréquemment pour apprendre vite.

## 5. Lien avec la capacité d'adaptation
Sans tests, chaque changement risque de casser l'existant : l'équipe ralentit. Avec TDD,
CI et refactoring, elle peut modifier le code rapidement et en sécurité.

## 6. Limites
XP demande de la discipline et un investissement initial ; certaines pratiques (client sur
site, binôme permanent) sont difficiles à tenir dans un contexte étudiant.
